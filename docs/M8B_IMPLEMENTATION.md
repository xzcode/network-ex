## Protected mobile P2P
Default is still relay-only. An explicit experimental Android toggle invokes StartWithDirect. The same managed authorization and WSS relay fallback remain. Pion ICE transport is wrapped by ICENet using the platform socket protection callback on UDP listeners, UDP dials, packet listeners and custom dialers. Unsupported TCP transport paths are refused; ICE uses IPv4 host/server-reflexive candidates and no TURN/mDNS. WSS signal sockets also use protection. Android app UID remains excluded from its own VPN, including system DNS; OS enumeration and DNS are not manually bound by the wrapper. The Go native descriptor adapter, peer /32 split routes, no default-route policy and existing service ACL remain. Link changes trigger a debounced restart when the active underlying network or its interface/address/route/DNS signature changes. User preference retained locally. Android-native network switch behavior and candidate gathering remain unverified.
