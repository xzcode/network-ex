# M8 Android first implementation (2026-11-26)

Version 0.8.0-dev-m8. Android source and reusable mobile core are implemented. No Android AAR/APK or iOS executable has been built or installed.

## Core
pkg/mobile exports a gomobile-compatible Platform, Session, Enroll, HasProfile, Forget and version API. Native code supplies an OS-owned raw IPv4 VPN descriptor and socket protection callback. The shared managed authorization loop, signed snapshots and relay leases, WireGuard engine and traffic guard are reused. The external adapter path does not invoke desktop network-administration commands. The descriptor is owned exactly once and closed on cancellation, expiry, revocation or reconfiguration; profile operations use an app-private advisory lock released on process death. Enrollment creates local identity and WireGuard keys, preserves administrator approval requirements and validates TLS. Secrets are not embedded in the app or uploaded to the repo.

Initial Android networking uses authenticated WSS relay only. HTTP management/probes and relay connections use a protection callback, as does the transport bind; rejecting protection prevents a socket from being used. Android excludes its own app UID from VPN routing, provides only authorized private peer /32 routes, checks visible physical route conflicts, and intentionally leaves ordinary Internet and IPv6 traffic outside the tunnel. No default route, remote subnet routes, gateway/exit role, IPv6 tunnel, TAP, broadcast, DNS override or direct ICE is offered in M8 initial mobile mode. Direct NAT traversal requires separately integrating all Pion sockets with Android network binding/protection and testing. Existing desktops retain their L3/L2 functionality.

## Android
apps/android contains Gradle application source, bilingual native Java UI, enrollment and approval/connection state, peer counters, forget confirmation, and foreground VpnService with Android consent, notification, stop/revoke lifecycle, and network change restart. It uses VpnService.Builder, restricts routes, transfers ownership with ParcelFileDescriptor.detachFd, and validates each supplied route. minSdk 26, target/compileSdk 35, AGP 8.7.3; build script pins gomobile/gobind version. No root required by design. System VPN permission and foreground-service compatibility must be verified on actual Android devices. It is not a privacy/full Internet VPN.

## Build
See apps/android/README.md and scripts/build-android.sh. Requires dedicated Android SDK 35, NDK, JDK17, Gradle 8.9 and Go. gomobile produces AAR then Gradle assembles debug APK; generated artifacts are ignored. Android 15+ 16KiB page-size support and production signing remain release gates. The current development host lacks Java, SDK, NDK and Gradle; it has limited free disk. No large SDK installed, no APK/AAR release. Pinned gomobile Java interface generation verified actual Mobile, Platform and Session method signatures. The x/mobile support dependency is pinned in go.mod, with corresponding x/sys, x/net, x/crypto upgrades.
