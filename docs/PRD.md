# 产品需求 M0

## 定位
面向个人、开发者、小团队的私有覆盖网络（overlay）。用户安装 Agent 后，通过稳定虚拟地址访问 SSH、HTTP、数据库、远程桌面等服务，不必为每个应用修改代码。官方托管可选，完全自托管为首要要求。并非匿名互联网代理或公共 VPN。

## 角色
系统管理员：初始化服务、控制注册、管理节点及审计。网络所有者：创建网络、邀请成员、批准设备、配置 ACL。成员：加入授权网络、查看可见设备、连接。设备：独立可撤销身份。Relay 运维者：仅管理被授权中继，不读取用户明文。

## 用户流程
1. 自建服务：部署单个程序、设置 TLS 与管理员、创建网络。
2. 设备接入：填写自定义 HTTPS 地址，使用一次性邀请/登录授权，生成本地密钥，等待审批（可由管理员配置自动批准）。
3. 创建/加入：分配虚拟 IP，获取有权限的 peer 及 ACL；后台服务接管路由。
4. 使用：设备列表展示自身地址、远端地址、状态、实际 P2P/Relay 类型、测量 RTT 和流量；复制地址后可从任意本机应用连接。
5. 断线：后台自动重试、直连失效回到中继、网络切换后重探测；用户可诊断并主动停止。
6. 移除：撤销设备、回收地址、传播策略并使旧租约失效；清理本机路由与凭据。

## 范围
P0: L3 IPv4、同网 peer、稳定虚拟地址、加密、直连+中继、设备审批、CLI/后台服务、桌面管理、完全自建、默认隔离、节点健康与审计。
P1: 多网络（禁止重叠路由或明确隔离）、子网路由、内部 DNS、ACL 细化、出口节点（显式授权）、集群、跨地区中继。
P2: 广播发现、L2 适配、移动端、社区节点（单独安全评审）。
非目标：自行发明密码协议、第一版支持所有 VPN 兼容协议、承诺 100% NAT 穿透、强制官方账号。

## UX/NFR
无强制云依赖；单服务器单程序可运行，默认 SQLite。桌面与 Agent 生命周期分离。简体中文/英文起步，支持跟随系统及语言切换；主题深/浅/灰，统一 EX 系列组件。网络状态来自真实事件；错误可定位到认证、路由、握手、直连或中继。默认仅安装授权 overlay 路由，不改默认出口、不自动暴露内网。流量统计区分 ingress/egress，不采集内容。任何性能目标须提供环境、版本、并发与数据量。
