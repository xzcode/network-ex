# 路线与验收

所有阶段状态在 STATUS.md；以下是交付定义，不代表已实现。每项记录真实环境、命令、输出、commit、已知缺陷；只有真实必要测试，不以 mock 代替实际验收。

| 阶段 | 批次与交付 | 退出条件 |
|---|---|---|
| M0 | 产品/架构/协议/安全/数据库/UI/部署/协作/目录边界 | 规范齐全，未决设计和测试门明确 |
| M1 | M1.1 Go 入口和版本锁；1.2 平台 TUN/route；1.3 静态 WG peer；1.4 安全 transport adapter；1.5 WSS 密文 relay/认证；1.6 CLI/状态/故障清理 | 两个 Linux 节点真实 TUN，TCP/UDP 应用数据直连和强制 relay 均通；抓包无明文；陌生 peer/匿名 relay 拒绝；关闭后路由清理；adapter roaming/close/MTU 确认 |
| M2 | 2.1 STUN；2.2 ICE 与信令；2.3 peer 路径状态机；2.4 fallback；2.5 重探测、网络变化；2.6 诊断和 NAT 实测 | 3 节点至少一条 P2P 一条 relay 同时真实通信；UDP 封锁仍可 relay；切换期间测 RTT/丢包/TCP 恢复时间；不能承诺零中断；双 NAT/CGNAT/IPv6/同 LAN 按矩阵记录 |
| M3 | 3.1 SQLite 迁移；3.2 管理员/账号；3.3 网络/IPAM；3.4 设备审批/revoke；3.5 信令快照；3.6 leases/ACL；3.7 Web 管理；3.8 all/management/relay | 从空白服务器注册三设备并完成真实组网；并发 IPAM 无冲突；撤销、跨租户、权限、TLS、持久化实测；单机无外部依赖 |
| M4 | 4.1 IPC；4.2 UI/主题/i18n；4.3 Windows；4.4 macOS；4.5 Linux；4.6 服务/安装 | 三平台分别安装、真实互通、后台运行、卸载清理；无签名/机器则 NOT RUN，不声称平台通过 |
| M5 | 动态注册、心跳、目录、双端调度、配额、drain、故障转移、集群存储/信令 | 运行时加入两个 relay，迁移/故障，跨 control 信令，实测带宽/并发/资源与重启 |
| M6 | 多网络隔离、子网路由、DNS、ACL、出口节点 | 冲突检测、显式授权、路由泄漏负向验收 |
| M7 | L2/广播发现技术论证、实际游戏联机 | 真实游戏房间发现与连接；风暴、环路、隔离、MTU 验证；不承诺所有游戏兼容 |
| M8 | Android/iOS | VPN API、移动网络切换、后台与签名分发验收 |
| M9 | 安装包、升级、SBOM、签名、部署指南、安全审查、Release | 可复现构建、备份恢复、升级回滚、安全阻断项清零；公开发行需许可证确认 |

## M1/M2 证据格式
设备/OS/NAT、build SHA、协议版本、实际虚拟 IP、选路状态、应用端到端结果、抓包摘要（脱敏）、失败原因、恢复时间、测试时长。示例拓扑：Linux A 与 B 位于隔离网络，C 做第三 peer；控制/中继服务与客户端独立。实验机由用户确认后选用，不对现有服务造成干扰。
## 性能
不承诺未经测试的直连比例/吞吐/在线数。记录 CPU、RSS、并发 peer、速率、P50/P95 延迟、丢包、切换耗时、实际出入口 GB。M1 重点功能；M5 容量基准和限制值依据测试冻结。
