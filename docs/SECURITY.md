# 安全基线

## 信任与威胁
攻击者可能控制公网、伪造设备、窃取 token、篡改/重放信令、中继恶意转发、滥用 STUN 或冒充客户端。管理服务是受信任的身份/密钥分发与策略权威，若被攻陷可替换公钥、授权恶意 peer；本设计不宣称防恶意控制面。端到端加密由 WireGuard 提供；中继仍可看见地址、时间、流量大小。后续可加用户验证指纹/密钥透明度。
## 强制要求
- TLS 1.2+（优先 1.3）标准实现，校验证书和主机名；私有 CA 显式导入。绝不自行实现加密算法；本机独立生成 identity key 与 per-network WG key，私钥不上传；密钥文件最小权限，禁止写入日志/前端持久化。
- 管理员/成员/设备/中继各独立身份与 scope；密码 Argon2id（参数按主机实测、限并发），一次性 invite 存哈希；短期 token、刷新 rotation、节点 proof of possession；保护 CSRF（管理 cookie SameSite/Origin/CSRF token）、XSS、SQL 注入、IDOR、SSRF、路径穿越。
- 多租户查询与写入每处检查 tenant/network，默认 deny，禁止仅依据虚拟 IP 认证。WG AllowedIPs 绑定 peer 与地址；Agent 入站/出站校验 ACL；Relay flow 同网授权。路由/防火墙变更最小范围，跨网络默认隔离，未经授权不得转发到物理 LAN/互联网。
- 撤销传播、租约过期 fail closed；建议控制面离线授权最长 15min（用户可调短，延长需显式风险确认）；即时撤销在离线场景不可保证。时钟偏移限制并记录；撤销后禁新会话、删除 peer/ACL、关闭 relay flow；地址不立即重分配。
- 限制 token/消息/连接/候选、审计高风险变更、保留期可配置；日志脱敏，诊断包用户确认；密钥与备份加密/权限保护；公开注册默认关闭。
- 依赖锁定、第三方 notices、SBOM、漏洞扫描、签名发布与校验和；驱动及 macOS 签名单独验证；无自动执行远程脚本。
## 验收负向测试
跨租户读取/写入、伪造 peer/源地址、过期或重放 invite/lease、撤销设备、篡改 WG 密文、TLS 错误、匿名 relay、超限流量、伪造节点、路由冲突、异常退出清理、控制面离线超期。任何失败阻止公开发布。外部安全评审与威胁复核为 M9 门槛。
