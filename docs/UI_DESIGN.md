# 界面设计规范

统一 EX 风格：桌面应用左导航、内容区、底部状态栏；浅/灰/深主题，浅色不刺眼、区域分隔清晰；控件高度统一（32–36px 建议），可拖动分栏、可排序列表、搜索不单独占整栏。键盘可达，避免只用颜色表示状态；支持中文/英文、系统语言优先。第一版不做假数据图表。

## 客户端页面
1. 欢迎/首次接入：服务端 HTTPS URL、证书信任信息、邀请/登录、设备名称、审批状态；切换服务器须明确退出/重新加入。
2. 网络：左侧网络列表/创建加入，右侧当前状态、虚拟 IP、连接/断开、权限、节点数；支持退出与复制 IP。
3. 设备：名称、平台、虚拟 IP、信令在线、数据面 P2P/Relay/未知、RTT、收发、最近握手；排序搜索，右键复制地址、查看诊断（不提供未授权远程操作）。
4. 拓扑/监控：真实 peer 连接关系、每条路径模式、速率/延迟/丢包的测量时间与单位、空状态；区分控制面在线与数据面连通。
5. 诊断：权限、TUN、路由冲突、TLS、STUN、ICE、relay、WG handshake；按阶段显示错误，导出脱敏日志需确认。
6. 设置：启动、关闭窗口行为、语言、主题、自定义 server、代理（是否适用显式显示）、更新、日志、证书信任、删除本机授权。
托盘/菜单栏展示连接状态、连接/断开、打开窗口、退出；关闭窗口不停止 Agent，退出与停止组网分离。

## Web 管理
首次管理员初始化、概览、租户/用户、网络/成员/审批、ACL、Relay 节点（在线、容量、流量、地区、drain、注册一次性 token）、审计、配置/备份说明。动作确认：撤销、删除、节点下线；错误码与 request ID 可复制。任何计数、在线、带宽须来源实际 API。管理员界面默认受认证，非公开。
M0 为布局与交互文字规范，实际视觉稿/可交互 UI M4，不宣称界面已实现。
