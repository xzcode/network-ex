细粒度流量规则

仅对已有组网权限的设备对生效。允许新建指定服务连接及其返回流量；未列服务被拒绝。

选择性互联网出口（Linux）

仅管理员可授权指定设备对及公网 IPv4 地址；客户端和网关均需本地启动参数明确同意。不是全流量 VPN。

游戏联机发现（Linux）

仅允许管理员指定 UDP 发现地址及端口；客户端必须本地启用。支持本网络广播、255.255.255.255 和 239/8 多播。每行一条 IPv4:端口；留空保存即关闭。
